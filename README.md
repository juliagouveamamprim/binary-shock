# Binary Shock

Binary Shock is a scientific-visualization project for analytic intrabinary
shock models implemented by [IBSEn](https://github.com/juliagouveamamprim/IBSEn).

## Current branch

`paper-figure-3d` develops a static three-dimensional explanatory figure
for an intrabinary-shock paper. It will translate a schematic model geometry
into a clear spatial composition with a fixed camera.

This work is in progress. The figure will be scientifically informed by the
analytic model, but it is not a hydrodynamic simulation or an automatic export
of a single IBSEn epoch.

## Project direction

The long-term project will share one physical-data foundation across three
presentations:

- a static paper figure;
- an interactive scientific scene; and
- an interactive artistic scene.

Implementation and rendering instructions will be added as the new figure is
built.
